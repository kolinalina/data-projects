# data-projects

exploring Global Ter**m Database incident records from 1970–2017 to uncover patterns, insights, and key questions.

pertanyaan:
1. bagaimana rata-rata jumlah ter**m pertahunnya apakah ada peningkatan? apakah ada wilayah tertentu dimana wilayah tersebut tidak mengikuti tren global?
2. apakah jumlah insiden dan korban jiwa berkorelasi? spot irregularities or outliers?
3. apa metode yang paling umum dilakukan untuk melakukan serangan? apakah berbeda di berbagai wilayah atau dari waktu ke waktu?
4. visualisasikan ke map lokasi region yang diserang
